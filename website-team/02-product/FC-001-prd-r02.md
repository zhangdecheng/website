## 3. 用户与使用端

- 目标用户：已在或准备在 TikTok / Instagram / YouTube 发布内容、**任一单平台**粉丝 ≥5,000、想接品牌合作或找机构协助的英文检索创作者。
- 使用端：Google 搜索结果摘要；英站首页 `https://www.flourishculturekol.com/`；独立创作者页（默认 `/creators`）；现有 Creator 联系/申请表单。
- 次要用户（本轮不优化）：品牌方咨询路径。

## 4. 目标 / 非目标

**必须做**

1. **首页（不改整体版式、不改 `/review/`）**
   - 英文 title / description / 必要 JSON-LD，与创作者页用词一致。
   - 首屏一句创作者合作说明 + 清晰入口（链到独立页，和/或预选 Creator 的联系区）。
   - 首页仍保留公司品牌定位；达人申请故事由独立页承接。
2. **独立英文创作者页（默认 `/creators`；占用则全站唯一改用 `/creator-partnership`）**
   - 真实独立 URL，GET 200，正文可与首页区分；禁止软回退首页。
   - 价值主张：Why Creators 四条同义表述。
   - 写清适合谁：三平台、三重点地区+其他、粉丝 ≥5,000（TikTok / Instagram / YouTube **任一单平台**）、服务三支柱。
   - CTA 必须是 Creator 申请语义，导向现有底部申请流程且 **Creator 已预选**；禁止仅用泛 Contact Us。
3. **跨页申请链**：创作者页 CTA → 既有表单 → Creator 预选正确 → 按原流程可提交（生产邮件送达抽测另授权）。
4. **发布产物**（进入工程群后才实施）：新页、真实 robots.txt、sitemap 含新页绝对 URL 进入 build/发布包；源码 / 构建包 / 公网一致。本群不开发。

**以后再做 / 本轮不做**

- 教程站、CMS、多页扩张、中文站、付费投放、OG 换图、启用 Routine、改邮件路由。
- 未批准就把 PDF 业绩数字写入 title/H1/meta。
- 把邮件量、总点击或 GEO 抽测「未出现」写成 SEO 失败。
- 本群点名 Codex / Ethan 开工；开发只在 Website 工程交付群、且用户另授开发权之后。

## 5. 业务规则

1. 语言：仅英文。
2. 服务一句话（对外）：brand matching + operations support + growth coaching。默认不用 exclusive talent management、zero-base training school。`incubator` / `management` / `agency` 仅在用户另批原词后使用。
3. 主张白名单：Why Creators 四条（全球品牌对接、商务合规结算、数据成长辅导、社群/供应链资源）；已公开的 Hong Kong East–West 定位、TikTok Shop TAP & CAP 可写，但条件性能力须标「普遍 vs 按项目」，无事实表不得写成人人可得。
4. 主张禁区：无来源数字/资质；A 桶 how-to（成为网红、涨粉/算法教程承诺）；未批收费/独家条款。
5. 申请三层口径（写入数据与验收，不混用）：
   - **申请送达**：Contact 以 Creator 提交且服务端成功并产生 Creator 路由邮件。
   - **有效申请**：送达 + 业务规定最低字段完整。
   - **目标匹配申请**：有效 + 符合平台/地区/粉丝门槛/合作意向。
   - **SEO 获客**：目标匹配（或有效）且有可核验搜索来源；否则标来源未知，**不计 SEO 获客**。
6. 本轮 SEO 交付及格线：页面与链路验收 + 数据可观察；**不绑定**邮件量。
7. 设计：默认复用现有组件与底部申请区，本阶段不新出图；独立页无法复用现有区块时由 Alex 单开设计 brief。
8. 粉丝门槛（已确认）：页上须写清 TikTok、Instagram 或 YouTube **任一单平台**达到 5,000 粉丝；不得写成三平台合计，也不得暗示必须三平台都满 5,000。
