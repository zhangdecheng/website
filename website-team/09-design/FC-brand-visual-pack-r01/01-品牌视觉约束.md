## 2. 配色：当前CSS基线

| 用途 | Token | 当前值 |

| 主黑色背景 | --black | #0A0908 |

沿用深色主体、珊瑚强调与少量暖金；不是要求把所有颜色都放到每张图片。避免企业蓝模板、大面积蓝紫科技渐变和强烈AI荧光。浅色区按既有页面使用，不将整站改成白绿。

以上不是已通过对比度审计的配色组合。新文字/背景组合仍须检查可读性。首页 `theme-color` 当前为 `#050505`，与CSS主黑色不同；本次记录差异，不自动修改。

## 3. 字体与排版

- 标题字体：Archivo，可变字重100–900；`assets/fonts/archivo-variable.woff2`。
- 正文字体：Space Grotesk，可变字重300–700；`assets/fonts/space-grotesk-variable.woff2`。
- 当前均本地托管，字体fallback为system-ui、-apple-system、sans-serif。不要为制作分享图无故引入另一套字体。
- 字号变量：label `clamp(11px, .78vw, 12px)`；body `clamp(14px, 1.1vw, 17px)`；lead `clamp(17px, 1.35vw, 20px)`；控件14px。页面最终字号还受选择器与响应式覆盖影响，不能将这些值直接当所有标题/正文的计算结果。
- 英文主内容；大标题强调清晰层级和自然换行。现有指定连接词使用 `and`，继承所在文本样式，不重新引入特殊ampersand字体，依据[连接词规格](../superpowers/specs/2026-08-30-and-word-connector-design.md)。
- 字体本地许可证分别位于 `node_modules/@fontsource-variable/archivo/LICENSE` 与 `node_modules/@fontsource-variable/space-grotesk/LICENSE`；这些是依赖文件路径，换环境须重新确认存在。分发字体时核对并保留适用许可说明，不因本清单而推定所有再分发方式获准。

## 4. 组件和图片规则

| 对象 | 保持的规则与当前实现 |
| --- | --- |
| 内容容器 | 最大1320px；gutter为clamp(28px,5vw,72px)，新模块沿用既有容器 |
| Logo | 使用透明lockup与独立mark；不得重画、拉伸、改字形、拆出新的品牌构图 |
| CTA | 既有.button：最小高度52px、横padding28px、圆角3px、14px/600；使用原有accent/dark变体，响应式以CSS为准 |
| 眉题 | 正文字体、字距.18em、uppercase；不套用到所有文字 |
| Service卡片 | 桌面图片/内容50:50；4px圆角，深色细边框；移动端单列、16:10图片，具体按现有断点 |
| 图片裁切 | Service为cover；招募图焦点20% center，camera-speaker图65% center；Hero保持既有完整人物/画面规则，不将Service裁切复制给所有图片 |
| 图像色调 | 当前Service默认saturate(.92)、contrast(1.03)、brightness(.93)；这是页面滤镜，新导出不要重复烘焙导致叠加 |
| 交互 | 保持现有hover/focus和prefers-reduced-motion处理；不擅自加入新动画库或整站动效 |
| 品牌轨道 | 按原批准名单与顺序；AIPER已被移除，不能因为文件仍在而加回 |
| 布局边界 | 局部图片或分享图任务不授权重构页面、改表单或改变产品信息架构 |

依据：[Service媒体规格](../superpowers/specs/2026-08-25-unified-service-media-design.md)、[Logo与伙伴区规格](../superpowers/specs/2026-08-24-homepage-partners-logo-design.md)、根目录styles.css。交付前实际核对桌面/移动渲染；本文不是本轮浏览器视觉验收报告。
